# Customer Segmentation using K-Means Clustering

This project implements a customer segmentation system using the K-Means clustering algorithm to group customers based on their annual income and spending behavior.

## Project Overview
- **Title:** Customer Segmentation using K-Means Clustering
- **Algorithm:** K-Means Clustering
- **Data:** Mall Customers Dataset (Age, Gender, Income, Spending Score)

## Objectives
- Identify high-value customers.
- Understand spending patterns.
- Help businesses optimize marketing resources.

## Technologies
- **Python**
- **Pandas** for data manipulation.
- **Scikit-learn** for machine learning.
- **Matplotlib & Seaborn** for data visualization.

## How to Run
1. Ensure you have the required libraries installed:
   pip install pandas numpy matplotlib seaborn scikit-learn
2. Open the `customer_segmentation.ipynb` notebook in Jupyter or VS Code.
3. Run all cells to see the clustering analysis and visualizations.

## Segmentation Results
The model segments customers into 5 distinct groups:
1. **Average Income, Average Spending**
2. **High Income, Low Spending**
3. **Low Income, High Spending**
4. **Low Income, Low Spending**
5. **High Income, High Spending**
